# Machine Learning from Scratch

A hands-on learning repository focused on understanding fundamental machine learning concepts through practical Python implementations.

## About This Repository

This repository documents my machine learning learning journey through small experiments, implementations, and datasets.

Topics currently explored include:

- Data preprocessing
- Classification
- Decision Trees
- Random Forest
- K-Means Clustering
- Model training and prediction
- Working with real-world datasets
- Iris dataset classification

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Purpose

The goal of this repository is to strengthen my understanding of machine learning fundamentals by implementing concepts through code rather than focusing only on theory.

## Status

🚧 This repository is continuously updated as I learn and experiment with new machine learning concepts.
